# C++: флот — лабораторная по ООП

Консольная программа для учёта судов трёх видов: подводная лодка, парусник, катер.

- Абстрактный базовый класс `Base` с чисто виртуальными методами ввода, вывода, сохранения и загрузки;
  `Submarine`, `Sailboat`, `Boat` их переопределяют.
- `Keeper` — свой динамический контейнер указателей на `Base` (растёт по мере добавления): добавление,
  удаление, редактирование, вывод всех объектов, сохранение в файл и загрузка из него.
- Конструкторы по умолчанию, с параметрами и копирования, геттеры и сеттеры, проверка ввода и исключения.

Сборка: Visual Studio 2022, проект `1l.vcxproj`.

---

**English.** A C++ OOP lab: an abstract base class with three ship types, a hand-written dynamic container of
polymorphic objects, and saving to / loading from a file.
